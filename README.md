# Clean PHP Blog (Чистый PHP 8.1+, Smarty 5, MySQL, Redis, Админ-панель)

Простой, быстрый и полностью рабочий веб-сайт блога, реализованный на **чистом PHP 8.1+ без использования сторонних фреймворков**, с реляционной базой данных **MySQL**, шаблонизатором **Smarty 5**, кэшированием в **Redis**, панелью администратора и стилями на **SCSS**.

---

##  Основной функционал

### 1. Публичная часть
- **Главная страница (`/`)**:
  - Выводит все категории, в которых есть хотя бы одна опубликованная статья.
  - Для каждой категории отображает **3 последних поста** (по дате публикации).
  - Кнопка **«Все статьи»** для перехода к категории.
- **Страница категории (`/category/{slug}`)**:
  - Название и описание категории.
  - **Сортировка статей**:
    - Сначала новые (по дате публикации)
    - Сначала старые
    - Самые популярные (по просмотрам)
    - Наименее популярные
  - **Пагинация** (по 6 статей на страницу с сохранением выбранной сортировки в URL).
- **Страница статьи (`/post/{slug}`)**:
  - Вся информация: изображение, заголовок, бейджи категорий, полный текст (с форматированием), счетчик просмотров, дата публикации.
  - **Атомарный инкремент просмотров** при каждом открытии статьи.
  - **Блок из 3 похожих статей** (подбираются по наибольшему количеству общих категорий с текущей статьей).

### 2. Панель администратора (`/admin`)
- **Дашборд (`/admin`)**:
  - Сводные виджеты статистики: общее количество статей, категорий и сумма всех просмотров.
  - **Топ-10 статей по просмотрам** (интерактивная таблица с фото, названием, категориями, просмотрами и кнопками перехода/редактирования).
- **Управление категориями (`/admin/categories`)**:
  - Просмотр списка категорий с количеством привязанных статей.
  - Создание (`/admin/categories/create`).
  - Редактирование (`/admin/categories/edit/{id}`).
  - Удаление (`/admin/categories/delete/{id}`) с каскадной очисткой связей.
- **Управление статьями (`/admin/posts`)**:
  - Пагинированный список всех статей с просмотрами.
  - Создание статьи (`/admin/posts/create`) с возможностью выбора **одной или нескольких категорий** (чекбоксы).
  - Редактирование статьи (`/admin/posts/edit/{id}`).
  - Удаление статьи (`/admin/posts/delete/{id}`).

### 3. Кэширование (Redis)
- Быстрое кэширование тяжелых выборок:
  - Секции главной страницы (`home:sections`, TTL 300 сек).
  - Список категорий для навигации (`categories:all`, TTL 300 сек).
- Автоматическая **инвалидация кэша** при создании, редактировании или удалении статей и категорий в админке.
- Безопасный fallback: если Redis временно недоступен, сайт продолжает штатно работать напрямую через MySQL.

### 4. Сидер данных (`bin/seed.php`)
- Консольный скрипт, который очищает таблицы и генерирует:
  - 6 актуальных IT/Digital категорий на русском языке.
  - 30 качественных статей с описаниями, текстами, изображениями с Picsum, датами и просмотрами.
  - Каждой статье назначается от 1 до 3 категорий (Many-to-Many).

##  Технологический стек и архитектура

- **PHP 8.2+** (строгая типизация `declare(strict_types=1)`, Enums, Typed Properties, Constructor Promotion).
- **Smarty 5.4** (шаблонизатор с наследованием `{extends}` / `{block}`, компонентами и безопасным автоэкранированием HTML).
- **MySQL 8.0** (InnoDB, Prepared Statements PDO, составной первичный ключ `post_categories(post_id, category_id)`, индексы на `views_count`, `published_at`, `slug`).
- **Redis 7** (In-Memory K/V хранилище для кэширования списков и меню).
- **SCSS / Dart Sass** (модульная архитектура стилей, CSS Grid, Flexbox, полная мобильная адаптивность).
- **Docker & Docker Compose** (Nginx, PHP-FPM, MySQL, Redis).

##  Запуск проекта

### Вариант А: Через Docker Compose (Рекомендуемый)

1. **Клонируйте репозиторий и перейдите в папку проекта:**
   ```bash
   cd tz1
   ```

2. **Запустите контейнеры Docker:**
   ```bash
   docker compose up -d --build
   ```
   *Контейнеры поднимут: Nginx (порт 8088), PHP-FPM 8.2, MySQL 8.0 (порт 3308), Redis 7 (порт 6381).*
   *MySQL автоматически инициализирует схему из `database/schema.sql`.*

3. **Запустите наполнение базы данных тестовыми данными (сидер):**
   ```bash
   docker compose exec php php bin/seed.php
   ```

4. **Откройте сайт в браузере:**
   -  Главная страница: [http://localhost:8088](http://localhost:8088)
   -  Панель администратора (Дашборд с Топ-10): [http://localhost:8088/admin](http://localhost:8088/admin)
   -  Управление категориями: [http://localhost:8088/admin/categories](http://localhost:8088/admin/categories)
   - Управление статьями: [http://localhost:8088/admin/posts](http://localhost:8088/admin/posts)

---

### Вариант Б: Локальный запуск (без Docker)

1. **Установите PHP-зависимости:**
   ```bash
   composer install
   ```

2. **Настройте файл окружения `.env`:**
   Укажите параметры доступа к локальному MySQL и Redis:
   ```ini
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_NAME=blog_db
   DB_USER=root
   DB_PASSWORD=your_password
   REDIS_HOST=127.0.0.1
   REDIS_PORT=6379
   ```

3. **Создайте базу данных и импортируйте схему:**
   ```bash
   mysql -u root -p blog_db < database/schema.sql
   ```

4. **Запустите сидер:**
   ```bash
   php bin/seed.php
   ```

5. **Запустите встроенный веб-сервер PHP:**
   ```bash
   php -S localhost:8000 -t public
   ```
   *Сайт будет доступен по адресу `http://localhost:8000`.*

##  Сборка стилей (SCSS)

В проекте уже находится скомпилированный файл `public/assets/css/style.css`.
При изменении исходников в `scss/`:

```bash
# Однократная сборка
npm run build:css

# Режим наблюдения за изменениями (watch)
npm run watch:css
```
